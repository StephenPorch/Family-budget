# 💎 Семейный Бюджет v0.6.5 (Family Budget)

Современное веб-приложение для ведения совместного семейного бюджета с поддержкой переходящих кумулятивных остатков, пакетного ввода чеков за любую дату из календаря, списка постоянных обязательных расходов с напоминалкой, прогнозирования трат на основе анализа прошлых месяцев и выгрузки в **XLSX / CSV / JSON / ИИ-отчет**.

---

## 🚀 Что нового в версии v0.6.5

1. **Календарь чеков и пакетный ввод за прошлые даты («Пачка чеков»):**
   - В модальном окне записи доступны быстрые кнопки `Сегодня`, `Вчера`, `Позавчера`, выбор любой даты из прошлого и тумблер **«📌 Пачка чеков»** (плюс кнопка **«+ Ещё чек»**). При разборе собранных бумажных чеков окно не закрывается и держит выбранную дату и карту.
   - На вкладке **«Операции и чеки»** добавлен интерактивный **Календарь чеков по дням месяца**: видно сумму по каждому дню, можно отфильтровать день в 1 клик или нажать `+ Чек сюда` в заголовке любого дня.

2. **Список постоянных обязательных расходов (Напоминалка + Планировщик):**
   - Учет мобильной связи, домашнего интернета, ЖКУ, аренды/ипотеки, секций и подписок с привязкой к конкретному счету (`👥 Общий котел`, `🧔🏻‍♂️ Карта мужа`, `👩🏼 Карта жены`) и редактированием.
   - Умные статусы напоминаний: 🔴 `Просрочен`, 🟠 `Оплата сегодня / Скоро (через N дн.)`, ⏳ `По плану до X-го числа`, 🟢 `✓ Оплачено` + баннер горящих платежей на главном дашборде.
   - При оплате постоянного расхода можно уточнить фактическую сумму по чеку и дату оплаты.

3. **Планируемые и предположительные расходы из анализа прошлых месяцев:**
   - Автоматический расчет среднего расхода по каждой категории за предыдущие месяцы + учет постоянных счетов категории.
   - Сравнение `Факт / План` с прогресс-барами, кнопка **«Заполнить план из прошлых месяцев»** в 1 клик и возможность вручную скорректировать плановый лимит любой категории.

4. **Удобный вывод и бэкап в XLSX, CSV, JSON и для нейросетей:**
   - **Скачать Excel (`.xlsx`)**: автономная генерация многостраничной книги Excel с 5 листами (`1_Сводка`, `2_Операции`, `3_План_и_Прогноз`, `4_Постоянные_счета`, `5_Копилки_и_Долги`).
   - **Универсальный CSV (`.csv` с UTF-8 BOM)**: понятная таблица, которая открывается в Excel/Google Таблицах без кракозябр, подходит для анализа нейросетью и служит **100% полным бэкапом** при обратной загрузке в приложение.
   - **Скопировать отчёт для ИИ**: готовый структурированный промпт со сводкой балансов, плана/факта и таблицей операций для вставки в чат с нейросетью.
   - **Старт с чистого листа**: кнопка очистки демо-данных в 1 клик с поддержкой `Undo`.

5. **Исправления по итогам аудита v0.6.0:**
   - Исправлена запись дат при оплате регулярных счетов и кредитов в выбранном прошлом/будущем месяце.
   - Исправлен откат `paidMonths` по кнопке «Вернуть» при нескольких платежах по кредиту в одном месяце.
   - Из графика «Темп по дням (Burn-down)» исключены переводы в копилки и кредиты, убрано дублирование 1-го дня, линия плана стартует с `0 ₽`.
   - Резерв обязательных платежей теперь считается раздельно для Общего котла, карты мужа и карты жены.
   - Добавлено редактирование копилок, кредитов и постоянных расходов, а также вывод средств из копилки (`− Взять из копилки`).
   - Исправлено округление в правиле `50/30/20` (сумма всегда равна `100%`) и перескок месяца при прогнозе закрытия кредита 31-го числа.
