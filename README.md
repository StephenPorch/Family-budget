# 💎 Семейный Бюджет (Family Budget)

Современное веб-приложение для ведения совместного семейного бюджета с акцентом на скорость ввода, прозрачность, кастомизацию и спокойствие.

---

## ⚡ Ключевые концепции и возможности

1. **Правило 3 секунд (Быстрая запись):**
   - Ввод расхода или дохода в 1-2 касания.
   - Фишки быстрой суммы (`+100 ₽`, `+300 ₽`, `+500 ₽`, `+1000 ₽`, `+3000 ₽`).
   - Раздельные категории для расходов и доходов:
     - **Расходы:** Продукты 🛒, Кафе ☕, Дом и ЖКУ 🏠, Транспорт 🚗, Развлечения 🎬, Здоровье 🌿, Шопинг 🛍️, Накопления 🎯.
     - **Доходы:** Зарплата 💰, Подработка 💻, Инвестиции 📈, Подарки 🎁, Другое 💵.
   - Возможность добавления и удаления **пользовательских категорий** с собственным эмодзи и сохранением в `localStorage`.
   - Выбор типа счета (**Общий 👥** / **Личный 👤**) и выбор даты операции (по умолчанию — текущий локальный день).

2. **«Свободно на день»:**
   - Автоматический расчет комфортного дневного лимита до конца текущего месяца исходя из общего баланса.
   - Помогает контролировать спонтанные покупки без жестких ограничений.

3. **Семейные копилки и цели:**
   - Интерактивные карточки целей с прогресс-барами и цветовыми градиентами.
   - **Клик по карточке** сразу открывает модальное окно для пополнения именно этой цели.
   - **Создание и удаление целей-копилок**: выбор названия, целевой суммы, начальных накоплений, иконки и палитры градиента.
   - Пополнение цели автоматически отражается в расходах семейного бюджета.
   - **Сквозной бухучет**: при удалении транзакции пополнения накопленная сумма в цели автоматически откатывается, предотвращая появление «фантомных» денег.

4. **История операций, поиск и фильтрация:**
   - Полнотекстовый поиск по названию операции или категории.
   - Фильтры в один клик:
     - По автору: **Все** / **🧔🏻‍♂️ Муж** / **👩🏼 Жена**
     - По типу: **Все типы** / **Расходы (-)** / **Доходы (+)**
     - По счету: **Все счета** / **Общие 👥** / **Личные 👤**
   - Удаление операций с диалогом подтверждения и автоматическим пересчетом статистики.

5. **Прозрачность двоих (Муж / Жена):**
   - Переключение роли («Муж 🧔🏻‍♂️» / «Жена 👩🏼») в шапке в один клик.
   - Индикатор распределения совместных трат в реальном времени.

6. **Адаптивность и доступность (a11y):**
   - Компактная Bento-сетка 2x2 на мобильных экранах (вместо громоздких вертикальных блоков) с защитой от переполнения длинными числами.
   - Закрытие модальных окон клавишей `Escape` и кликом по фону (backdrop), семантика `role="dialog"` и `aria-modal="true"`.
   - Поддержка пользовательского масштабирования (WCAG 1.4.4 Resize Text).
   - Соответствие WCAG AA по контрастности текста и служебных элементов (`text-stone-500` / `text-stone-600` на светлом фоне).
   - Атрибуты `aria-label` для всех интерактивных элементов (закрытие, удаление, FAB, палитра цветов, эмодзи, сброс поиска).

7. **Автономность и надежность:**
   - Все данные хранятся локально в `localStorage` браузера (`family_budget_txs`, `family_budget_goals`, `family_budget_custom_categories`) с защитой от повреждения данных.
   - Корректная работа с локальными часовыми поясами (без сдвига дат из-за UTC).
   - Данные не передаются на сторонние серверы и не покидают ваше устройство.

## 🛠️ Стек технологий

- **React 18** — хуки `useState`, `useMemo`, `useEffect`.
- **Vite 5** — сборщик проекта и локальный сервер.
- **Tailwind CSS 3** — стили, Bento-сетка, адаптивный дизайн.
- **Lucide React** — векторные иконки интерфейса.

## 🚀 Варианты запуска

### Вариант 1. Автономный запуск без Node.js (Рекомендуется для быстрого старта)
Просто откройте файл `standalone.html` двойным кликом в браузере (Chrome, Edge, Safari, Firefox).  
Он полностью самодостаточен, подключает Tailwind и React через CDN и работает офлайн после первой загрузки библиотек.

### Вариант 2. Запуск в режиме разработки (Vite)
Требуется установленный Node.js 18+.

```bash
# 1. Перейти в папку проекта
cd c:\Users\zemichev\YandexDisk\side_projects\family-budget

# 2. Установить зависимости (если еще не установлены)
npm install

# 3. Запустить dev-сервер
npm run dev
```

Приложение откроется по адресу `http://localhost:3000`.

### Сборка для продакшена:
```bash
npm run build
```
Собранные статические файлы будут сохранены в директории `dist/`.
