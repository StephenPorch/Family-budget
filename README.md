# 💎 Семейный Бюджет v0.6.0 (Family Budget)

Современное веб-приложение для ведения совместного семейного бюджета с акцентом на скорость ввода, прозрачность, переходящие кумулятивные остатки, контроль обязательных счетов и психологическое спокойствие.

---

## ⚡ Ключевые концепции и возможности v0.6.0

1. **Кумулятивный переходящий остаток кошельков:**
   - Баланс кошельков (**Общий котел 👥**, **Личный счет мужа 🧔🏻‍♂️**, **Личный счет жены 👩🏼**) рассчитывается накопительно по всем операциям до конца выбранного месяца (`t.date <= endOfSelectedMonth`). 1-го числа нового месяца баланс больше не обнуляется!
   - В нижней строке карточки каждого кошелька наглядно отображается чистый финансовый поток за выбранный месяц: `+Доходы / −Расходы`.

2. **Безопасный лимит в день с резервом на платежи:**
   - Формула расчета: `Math.max(0, Math.round((activeBalance - unpaidMandatoryThisMonth) / daysLeft))`.
   - Автоматически резервирует сумму под неоплаченные обязательные счета месяца и долги, защищая от случайных перетрат.
   - Подсказка в карточке лимита сообщает точную сумму заблокированного резерва.

3. **Изоляция накоплений и кредитов:**
   - Транзакции с `goalId` или `debtId`, а также категории «Накопления» и «Долги и кредиты» исключены из пирога потребительских трат и структуры расходов.
   - Выделены в отдельный прозрачный показатель **«Отложено и погашено»**.

4. **Две шкалы участия в общем котле:**
   - **«Вклад в доходы котла»**: соотношение доходов, внесенных мужем и женой в общий бюджет.
   - **«Оплата общих покупок»**: прозрачное распределение оплаты совместных потребительских нужд.

5. **Четвертая вкладка «Долги и платежи»:**
   - **Платежный радар месяца**: список обязательных регулярных платежей (аренда/ипотека, ЖКУ, связь, секции) с оплатой в 1 тап. Оплата создает операцию, присваивает статус `✓ Оплачено` и моментально разблокирует резерв в дневном лимите.
   - **Долги и кредиты (Обратные копилки)**: интерактивные карточки с прогресс-баром выплаты, суммой платежа, днем месяца, прогнозом даты закрытия кредита и кнопкой «Внести платёж» со сквозным учетом и защитой от фантомных сумм по Undo.
   - Локальное сохранение в `family_budget_recurring` и `family_budget_debts`.

6. **Чистые интерактивные SVG-графики на вкладке «Обзор»:**
   - **Темп по дням (Burn-down chart)**: плановая траектория бюджета vs фактические расходы по дням месяца со статусом-вердиктом (🟢 «В графике» / 🟠 «Опережение плана»).
   - **3 корзины (Светофор 50/30/20)**: распределение расходов на Базу (50%), Хотелки (30%) и Будущее (20%) + авто-маркеры динамики категорий к прошлому месяцу (`+4 200 ₽ к сент. 🔺`).
   - **Динамика 6 мес**: столбчатая диаграмма доходов, расходов, сбережений и нормы накоплений (%) за последние 6 месяцев.

7. **Правило 3 секунд и удобство модальных окон:**
   - Быстрый выбор источника/получателя средств в 1 касание из 3 кнопок в ряд: `👥 Общий котел` | `🧔🏻‍♂️ Карта мужа` | `👩🏼 Карта жены`.
   - **Защита связок**: блокировка переключения типа Расход/Доход при редактировании операций, привязанных к целям или кредитам.
   - Чипсы быстрых сумм, инлайн-создание категорий с эмодзи, нативный выбор даты.

8. **Система мягких Undo-уведомлений:**
   - Вместо навязчивых `window.confirm` все удаления транзакций, категорий, копилок и кредитов сопровождаются мягким тостом с кнопкой **«Вернуть»**.
   - Полный откат состояния копилок и кредитов при отмене.

9. **Автономность и надежность:**
   - Локальное хранение в `localStorage` без отправки персональных данных на серверы.
   - Доступна единая офлайн-версия `standalone.html`, открывающаяся в любом браузере двойным кликом.

## 🛠️ Стек технологий

- **React 18** — хуки `useState`, `useMemo`, `useEffect`, `useRef`.
- **Vite 5** — сборщик проекта и локальный сервер разработки.
- **Tailwind CSS 3** — стили, Bento-сетка, адаптивная верстка.
- **Lucide React** — векторные иконки интерфейса.
- **Pure SVG** — визуализация финансовых графиков без сторонних тяжелых библиотек.

## 🚀 Варианты запуска

### Вариант 1. Автономный запуск (без Node.js)
Откройте файл `standalone.html` двойным кликом в любом современном браузере (Chrome, Edge, Safari, Firefox). Работает офлайн.

### Вариант 2. Режим разработки (Vite)
```bash
# 1. Перейти в каталог проекта
cd c:\Users\zemichev\YandexDisk\side_projects\family-budget

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер
npm run dev
```

### Прогон тестов:
```bash
npm test
```

### Синхронизация автономного файла:
```bash
npm run sync:standalone
```

### Сборка для продакшена:
```bash
npm run build
```
Собранные статические файлы сохраняются в `dist/`.
