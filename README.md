# 💎 Семейный Бюджет (Family Budget)

Современное веб-приложение для ведения совместного семейного бюджета с акцентом на скорость ввода, прозрачность и спокойствие.

---

## ⚡ Ключевые концепции

1. **Правило 3 секунд:**
   - Быстрый ввод расхода или дохода без лишних шагов.
   - Фишки быстрой суммы (`+100 ₽`, `+300 ₽`, `+500 ₽`, `+1000 ₽`, `+3000 ₽`).
   - Наглядная сетка категорий с крупными иконками.

2. **«Свободно на день»:**
   - Автоматический расчет комфортного дневного лимита до конца текущего месяца исходя из общего баланса.
   - Помогает контролировать спонтанные покупки без жестких ограничений.

3. **Копилки и цели:**
   - Визуальные карточки целей с прогресс-барами и цветовыми градиентами.
   - Быстрое пополнение цели одной кнопкой с автоматическим отражением в расходах бюджета.

4. **Прозрачность двоих (Муж / Жена):**
   - Переключение роли («Муж 🧔🏻‍♂️» / «Жена 👩🏼») в шапке в один клик.
   - Индикатор распределения совместных трат в реальном времени.
   - Разделение транзакций на «Общий» и «Личный» бюджет.

5. **Автономность и приватность:**
   - Все данные хранятся локально в `localStorage` браузера (`family_budget_txs`, `family_budget_goals`).
   - Данные не покидают ваше устройство.

---

## 🛠️ Стек технологий

- **React 18** — компонентная архитектура, хуки `useState`, `useMemo`, `useEffect`.
- **Vite 5** — быстрая сборка и HMR.
- **Tailwind CSS 3** — утилитарные стили, Bento-сетка, адаптивный дизайн для мобильных и ПК.
- **Lucide React** — минималистичные векторные иконки.

## 🚀 Варианты запуска

### Вариант 1. Автономный запуск без Node.js (Рекомендуется для быстрого старта)
Просто откройте файл `standalone.html` двойным кликом в браузере (Chrome, Edge, Safari, Firefox).  
Он полностью самодостаточен, подключает необходимые скрипты через CDN и сохраняет данные в `localStorage`.

### Вариант 2. Запуск в режиме разработки (Vite)
Требуется установленный Node.js 18+.

```bash
# 1. Перейти в папку проекта
cd c:\Users\zemichev\YandexDisk\side_projects\family-budget

# 2. Установить зависимости (если еще не установлены)
npm install

# 3. Запустить dev-сервер
npm run dev
```

Приложение откроется по адресу `http://localhost:3000`.

### Сборка для продакшена:
```bash
npm run build
```
Собранные статические файлы будут в директории `dist/`.

## 📊 Начальные данные

При первом запуске приложение инициализируется демонстрационными данными:
- **Транзакции:** покупки в супермаркете, кафе, аванс по работе, оплата ЖКХ, пополнение цели «Отпуск».
- **Цели:**
  - 🏔️ Отпуск в горах (цель: 200 000 ₽)
  - 🛡️ Подушка безопасности (цель: 450 000 ₽)
  - 🖥️ Апгрейд рабочего места (цель: 120 000 ₽)
- **Категории:** Продукты, Кафе, Дом и ЖКУ, Транспорт, Развлечения, Здоровье, Шопинг, Накопления.
