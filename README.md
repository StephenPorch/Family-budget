# Семейный Бюджет v0.7.1

Современное веб-приложение для совместного ведения семейного бюджета (Женя и Ксюша), планирования постоянных платежей, прогнозирования трат и аналитики с модульной архитектурой.

## Что нового в версии v0.7.1 (По итогам строгого аудита v0.6.5)

### 1. Модульная архитектура и оптимизация рендеринга (`React.memo`)
- Монолитный `src/App.jsx` декомпозирован на независимые модули:
  - `src/utils/dateUtils.js` — работа с датами, нормализация форматов РФ-банков (`DD.MM.YYYY`, `DD/MM/YYYY`, `YYYY-MM-DD`) и парсер валютных сумм (`"-1 450,50 ₽"`).
  - `src/utils/financeCore.js` — чистые функции бухгалтерского ядра (`calculateSafeDailyBudget`, `mergeTransactions`, `calculateDebtPayoff`, `calculateHistoricalForecast`).
  - `src/utils/storage.js` — безопасная работа с `localStorage`, перехват `QuotaExceededError` и базовые справочники.
  - `src/utils/xlsx.js` — генератор нативных 4-листовых книг Microsoft Excel (`.xlsx`, стандарт OpenXML + CRC32 ZIP) без внешних зависимостей.
  - `src/utils/csv.js` — генератор и RFC 4180 парсер CSV с поддержкой UTF-8 BOM.
  - `src/hooks/useFocusTrap.js` — хук клавиатурной доступности (`Focus Trap`, WCAG 2.1.2) для модальных окон.
  - `src/components/analytics/ChartsSection.jsx` — мемоизированные SVG-графики динамики за 6 месяцев и распределения категорий.
  - `src/components/calendar/ReceiptCalendar.jsx` — мемоизированный интерактивный календарь чеков с адаптивной версткой для узких экранов (`360px`).
  - `src/components/modals/TransactionModal.jsx`, `ExportBackupModal.jsx`, `EntityModals.jsx` — изолированные модальные окна с собственным локальным состоянием полей ввода (ввод текста не вызывает перерисовку корневого дашборда).
- Скрипт `scripts/sync-standalone.cjs` автоматически собирает модульные исходники из `src/` в автономный `standalone.html` (единый бандл, работающий по двойному клику без сервера).

### 2. Бухгалтерская математика и защита от кассовых разрывов
- **Блокировка смены типа для регулярных платежей:** в `isEditingLockedType` добавлена проверка `Boolean(tx?.goalId || tx?.debtId || tx?.recurringId)`, исключающая случайное превращение оплаченного счета ЖКУ/интернета в доход при редактировании.
- **Индикация кассового разрыва (отрицательного баланса):** при превышении расходов над балансом (`rawSafeBalance < 0`) карточка баланса счета подсвечивается аварийным `rose-600` (`⚠️ Дефицит счета`), а 4-я карточка KPI выводит реальную сумму дефицита (`Кассовый разрыв: −X ₽`) вместо маскировки нулем (`0 ₽/день`).
- **Защита фильтра месяца при разовой записи чека из прошлого:** при добавлении забытого чека за прошлый месяц фильтр дашборда больше не перебрасывает пользователя в прошлое автоматически — вместо этого во всплывающем уведомлении появляется кнопка быстрого перехода `Открыть <Месяц>`.

### 3. Безопасный импорт CSV/JSON и поддержка банковских выписок РФ
- **Выбор режима импорта (`Merge` vs `Replace`):** в окне бэкапа добавлен переключатель:
  - `➕ Дополнить базу (Merge)` (по умолчанию) — объединяет операции без удаления текущей истории и автоматически отсекает дубликаты по `id` и сигнатуре `date|type|amount|title|account`.
  - `🔄 Заменить всю базу (Replace)` — полная перезапись с возможностью отката через `Вернуть (Undo)`.
- **Парсинг дат и сумм из банковских выписок (Сбер, Т-Банк, ВТБ):** функция `normalizeImportedDate` автоматически конвертирует даты `DD.MM.YYYY`, `DD/MM/YYYY`, `DD-MM-YYYY` и `DD.MM.YY` в стандарт `YYYY-MM-DD`, сохраняя работоспособность группировки по месяцам.

### 4. Мобильная эргономика (`360px–375px`) и доступность (`WCAG AA`)
- **Нижняя панель навигации (`<nav>`):** компактные подписи в одно слово (`Обзор`, `Чеки`, `+`, `Счета`, `Копилки`) с `whitespace-nowrap` и контрастом `text-stone-600` (`7.0:1`).
- **Компактная сетка календаря (`ReceiptCalendar`):** адаптивные ячейки с компактным форматированием сумм (`850`, `3.5k`, `26k`), исключающим горизонтальный скролл на экранах `360px`.
- **Доступность (`WCAG 1.4.3 & 2.1.2`):** повышен контраст вторичных подписей (`text-stone-500` / `text-stone-600`) и внедрен перехват фокуса (`useFocusTrap`) во всех модальных окнах.

## Быстрый старт

### Вариант 1: Автономный запуск (без установки Node.js)
Откройте файл `standalone.html` двойным кликом в любом браузере на ПК, смартфоне или планшете.

### Вариант 2: Разработка и тестирование (Vite + Node.js)
```bash
npm install
npm test          # Запуск модульных тестов бухгалтерского ядра и проверки standalone.html
npm run sync      # Пересборка standalone.html из модульных файлов src/
npm run dev       # Запуск dev-сервера Vite
```
