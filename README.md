# Семейный Бюджет v0.8.0

Современное веб-приложение для совместного ведения семейного бюджета, планирования постоянных платежей, прогнозирования трат и аналитики с Personal-First архитектурой, переводами между кошельками и поддержкой PWA.

## Что нового в версии v0.8.0 (Переводы между кошельками ⇄ + закрытие аудита v0.7.8)

### 1. Прямые переводы между кошельками и «Семейным резервом» (`type: 'transfer'`, `⇄`)
- **3-й тип операции «Перевод (⇄)» в окне записи (`TransactionModal.jsx`):** позволяет в один клик переводить средства между личным кошельком партнера 1, личным кошельком партнера 2 и «Семейным резервом» (общим котлом) с готовыми пресетами (`В резерв → 👥`, `Партнеру →`, `Из резерва ←`).
- **Чистая бухгалтерия без искажения расходов:** внутренние переводы изменяют кумулятивные остатки обоих кошельков и учитываются во вкладе партнера в семейный резерв (`calculatePartnerComparison`), но **не раздувают** потребительские траты месяца, прогноз категорий и столбцы графиков.
- **Фильтрация и индикация:** в истории операций добавлен фильтр `⇄ Переводы`, а строки переводов отображают маршрут (`Откуда → Куда`) и индиго-бейдж `⇄ Перевод`.

### 2. Полное закрытие замечаний технического аудита v0.7.8
- **Целостность `standalone.html` (`scripts/sync-standalone.cjs`):** в сборщик автономной версии включены модули `src/hooks/useBackdropDismiss.js` и `src/components/ErrorBoundary.jsx`, а корневой компонент обернут в `<ErrorBoundary>`. Скрипт `scripts/test-standalone.cjs` теперь автоматически проверяет наличие всех обязательных хуков и классов внутри сгенерированного HTML.
- **100% сохранность настроек при экспорте и импорте (`.json` и `.csv`):**
  - Настройки горизонта безопасного лимита (`safeLimitConfig`: режим, числа зарплаты `paydays`, `fixedDays`) сохраняются и восстанавливаются при JSON-экспорте/импорте.
  - Флаг свободного графика кредита/долга (`isRegular: false` / `flexible`) и маршруты переводов (`from:...`, `to:...`) сохраняются в структурированном CSV-бэкапе и восстанавливаются при импорте.
- **Визуализация дней зарплаты на графике «Темп по дням» (`ChartsSection.jsx`):** при выборе режима горизонта «До ЗП / аванса» на SVG-графике `Burn-down` отображаются вертикальные пунктирные отметки дат выплат (`ЗП 10`, `ЗП 25`).
- **Чистая сборка архива:** удалены устаревшие демонстрационные файлы `v0.6.5` из корня проекта, пути внутри ZIP-архива нормализованы по стандарту POSIX (`/`), расширен набор модульных тестов (`9/9` тестовых наборов в `scripts/unit-tests.cjs`).

## Что было добавлено в версиях v0.7.6 – v0.7.8

- **Настраиваемый горизонт безопасного лимита (`SafeLimitConfigModal`, v0.7.8):** клик по 4-й KPI-карточке открывает настройку горизонта деления свободных средств: `📅 До ЗП / аванса` (по числам месяца, например `10` и `25`), `🗓️ Конец месяца`, `⏳ Срок в днях` (`7`, `14`, `30`, `60`, `90` дн.) и `🎯 До конца года`.
- **Защита модальных окон при выделении текста (`useBackdropDismiss.js`, v0.7.7):** закрытие модального окна по клику на подложку срабатывает только если и `mousedown`, и `mouseup` произошли непосредственно на оверлее.
- **Широкоформатная сетка `max-w-7xl` и предохранитель `ErrorBoundary` (v0.7.6 – v0.7.7.1):** адаптивная шапка без переполнения на `1024px–1440px`, экран аварийного сброса кэша Service Worker при сбоях и стратегия `Network-First` для HTML-навигации в PWA.

## Что было добавлено в версиях v0.7.1 – v0.7.5 (Personal-First & PWA)

- **Архитектура «Личный баланс на первом месте»:** карточка 1 отображает личный кошелек владельца текущего смартфона, карточка 2 — личный кошелек партнера, карточка 3 — «Семейный резерв».
- **Кастомизация профилей (`ProfileEditModal`):** настройка имен, эмодзи-аватаров и владельца устройства с сохранением в `localStorage`.
- **Гибкие долги (`isRegular: false`):** поддержка долгов со свободным графиком погашения без принудительного вычитания из дневного лимита.
- **Модульная архитектура ES Modules + `React.memo`:** декомпозиция кода на `src/utils/`, `src/hooks/` и `src/components/`.

```bash
npm install
npm test          # Запуск 9 наборов модульных тестов и проверки целостности standalone.html
npm run sync      # Пересборка standalone.html из модульных файлов src/
npm run dev       # Запуск dev-сервера Vite
```
